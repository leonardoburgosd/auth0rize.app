Guía rápida

  1. Clona el repositorio frontend: git clone https://github.com/leonardoburgosd/auth0rize.app
  2. Clona el repositorio backend: git clone https://github.com/leonardoburgosd/auth0rize.api
  3. Configura las variables de entorno
  4. Ejecuta el proyecto backend en .NET Core
  5. Ejecuta el proyecto frontend en Angular
  6. Ingresa http://localhost:4200 en tu navegador
